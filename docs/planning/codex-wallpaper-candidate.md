## 统一人工验收门槛

1. 按 `launcher/README.md` 完成界面、本地媒体、四类 WE 条目、轮播、多窗口、停用和撤销。
2. 在真实 Codex 做 30–60 分钟原版/静态/动态对照，记录 CPU、GPU、内存、帧率、播放器数和交互响应，确认资源预算。
3. 同一候选版本完成至少 8 小时连续使用；有修复后重新确认受影响场景。
4. 8 小时通过后开始 7 天日常观察。期间版本变化时重新核对兼容散列。

联网 Web、Scene 原生覆盖率和长期稳定目前都不能判定通过。专用入口完成 8 小时验收，需要用户明确接受它作为该候选版本的入口。
