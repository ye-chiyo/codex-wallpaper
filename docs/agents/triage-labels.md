# Triage Labels

工程技能使用以下五种标准 triage 角色。
本项目保留默认名称，在本地任务文件的 `Status:` 行中使用。

| 标准角色          | 本项目名称        | 含义                            |
| ----------------- | ----------------- | ------------------------------- |
| `needs-triage`    | `needs-triage`    | 需要维护者评估                  |
| `needs-info`      | `needs-info`      | 等待提出者补充信息              |
| `ready-for-agent` | `ready-for-agent` | 规格明确，可交给 agent 独立执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实施                    |
| `wontfix`         | `wontfix`         | 不予实施                        |

当技能要求应用某个 triage 角色时，使用表中的本项目名称。

如需调整名称，修改“本项目名称”列，并同步相关任务状态。
Wayfinding 的领取和解决状态遵循 `issue-tracker.md`，
不作为本表的 triage 标签。
