# 01: 主界面静态壁纸与即时停用

**阶段：** P1 · 接入

**What to build:** 用专用入口打开日常 Codex 时，在匹配的真实主界面自动显示一层静态渐变；关闭壁纸即恢复原界面，停用状态可跨重启保留。

**Blocked by:** 无。专用入口 P0b 已通过；不依赖 13。

**Status:** ready-for-human

**Completed:** 2026-11-13

**复用边界：** 复用本仓库已验收的专用启动器、官方包/日常数据路径/环回监听归属核验及只读探针。为 Codex 新做独立的静态背景层、启停状态与清理；本单不引入 DSH 运行时、播放器、素材库或联网能力。

## 验收标准

- [x] 离线验证：只接受匹配版本、已核对归属的实例和预期主界面；版本、目标或归属不符时保持原界面。不向其他窗口、内嵌网页或普通启动的实例应用背景。
- [x] 重复应用只存在一层；即时停用清除适配新增的节点与样式，不影响宿主布局、输入、焦点和滚动。已停用状态在重开后仍生效。
- [x] 原入口、官方安装文件和日常 profile 保留；不创建空白 profile，不读取账号凭据或聊天内容。验证报告只记必要状态。

## 人工验收

- [x] 离线检查通过并准备好候选版本后，由用户另选空闲时段手动做三次专用入口冷启动：至少一轮验证启用后自动显示且只有一层，停用后即时恢复，并在后续冷启动确认停用保持；再次启用可恢复背景。
- [x] 用户确认仍是原账号、同一个已有聊天可打开；出现登录页、意外导航或目标异常时中止，不在实验界面重新登录。按原入口对照核对撤销；退出专用实例后旧调试监听关闭。

**执行说明：** 离线候选可在收到实施指令后先做；真实验收另行排期。壁纸停用只撤销界面层，断开连接不等于关闭调试监听。
