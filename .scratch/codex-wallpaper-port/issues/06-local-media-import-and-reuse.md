# 06: 导入本地图片和视频，并确认代码复用清单

**阶段：** P4 · 素材

**What to build:** 导入并切换本地图片、视频，重开恢复；明确原项目哪些代码实际进入移植。

**Blocked by:** 05

**Status:** ready-for-human

**复用边界：** 优先复用可脱离 DSH 的清单、元数据和媒体准备逻辑；为 Codex 新做本地供料、配置接线和故障提示。

## 验收标准

- [ ] 本地图片和视频分别有可播放样本，导入、切换和重开恢复正常；断网仍可用，素材被移动或删除时跳过并提示。
- [ ] 记录上游版本、实际复用模块、Codex 适配点及许可；保留所需声明，独立核对素材和字体授权。

## 人工验收

- [ ] 用你选择的本机图片和视频在实际候选版本中导入、切换、断网重开，并移走测试副本验证缺失提示。
