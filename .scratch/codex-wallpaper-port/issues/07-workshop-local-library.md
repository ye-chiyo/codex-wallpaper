# 07: 浏览本机已下载的 Wallpaper Engine 壁纸

**阶段：** P4 · 素材

**What to build:** 从壁纸库识别本机已下载的 Wallpaper Engine 内容和可用状态。

**Blocked by:** 06

**Status:** ready-for-human

**复用边界：** 优先复用上游可分离的库存、类型和元数据解析；为 Codex 新做本机路径选择、库入口与错误状态。

## 验收标准

- [ ] 可发现并区分图片、视频、Scene、Web；坏条目不导致全库不可用，清楚显示可用性。
- [ ] 不自动订阅或下载创意工坊内容；核心扫描和浏览离线可用。

## 人工验收

- [ ] 用本机已下载的实际素材和一个缺失条目核对分类与可用性；缺少代表性类型时记录缺口，不把识别当作播放通过。

## Comments

- 2026-11-13：只读本机扫描发现 106 个条目：视频 37、Scene 64、Web 4、图片 1；清单不向渲染器暴露绝对路径。离线夹具验证坏主文件和越界路径被丢弃，图片、视频、Scene、Web 可分类。
- 2026-11-15：用户报告大量已下载素材显示不可播放或预览降级。按本机文件统计，旧预算将 93/106 条目误判：预览上限仅 384 KiB，而预览中位数约 0.63–0.86 MiB、最大约 1.04 MiB；34/37 视频超过旧 16 MiB 上限，6/64 Scene 超过旧 64 MiB 上限。现改为可见卡片按需加载预览、选择后按需读取主素材，卡片在宿主就绪后显示“按需加载”，不再把未预载误标为损坏。
