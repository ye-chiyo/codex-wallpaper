# 12: 故障、更新不兼容与卸载

**阶段：** P5 · 维护

**What to build:** 在适配失败或 Codex 更新不兼容时保留可用原界面，提供可视化停用和卸载。

**Blocked by:** 08、09、10、11

**Status:** ready-for-agent

**复用边界：** 参考原项目资源清理和恢复策略；为 Codex 重做兼容检查、有限恢复和卸载。官方包、原入口及日常 profile 不纳入卸载。

## 验收标准

- [ ] 模拟版本变化、坏配置、素材丢失及辅助程序退出，结果为降级或关闭壁纸，Codex 继续工作；重试有上限。未知版本不自动启用。
- [ ] 停用及时移除适配新增的界面和播放资源。卸载只移除本项目的入口、辅助程序及自有文件，不留下常驻进程或影响原入口。

## 人工验收

- [ ] 用户用候选版本验证一键停用和卸载；正常退出专用实例，再从原入口启动，确认旧监听已关闭、原账号和同一已有聊天可用。用模拟版本不匹配验证，不为测试主动升级正在使用的 Codex。
