# 10: 可视化壁纸库、收藏与轮播

**阶段：** P5 · 日用

**What to build:** 不用终端或模型即可浏览、导入、切换、收藏、建立播放列表和定时轮播。

**Blocked by:** 07

**Status:** ready-for-agent

**复用边界：** 优先复用原项目壁纸选择、轮播规则和可独立迁移的数据逻辑；为 Codex 新做管理入口与全局状态接线。

## 验收标准

- [ ] 收藏、播放列表、轮播配置和选择跨窗口一致，重开可恢复；坏素材跳过并提示。
- [ ] 轮播不积累播放器；可管理已验收的素材类型，不把尚未验收的播放能力计作完成。

## 人工验收

- [ ] 通过真实可视化入口建列表并等一次自动切换，重开后检查恢复，在另一窗口核对一致性并移走测试素材核对提示。
