# 05: 多窗口恢复与性能基线

**阶段：** P3 · 运行

**What to build:** 多个窗口共享本机配置，但独立决定是否播放；建立本机性能与恢复基线。

**Blocked by:** 02、03、04

**Status:** ready-for-human

**复用边界：** 参考原项目的降帧和运行监督设计；为 Codex 新做多窗口状态、重连去重和对照测量。

## 验收标准

- [ ] 新窗口读取相同配置，每个窗口独立判断可见性；反复切换和重连不累积播放器，关闭的窗口不继续播放。
- [ ] 用同一组操作、窗口数和动态素材做原版、静态、动态对照，记录 CPU、GPU、内存、帧率、播放器数量和交互响应；记录内存趋势，基于实测提出预算和恢复时限。

## 人工验收

- [ ] 在真实 Codex 做 30–60 分钟短时运行与对照记录，开关多个窗口并验证一个窗口暂停不影响另一个。正式长时验收前确认预算与恢复时限。

## Comments

- 2026-11-13：离线候选已实现同源全局配置、`storage` 事件跨窗口同步、各窗口独立可见性判断、单播放器替换和运行状态计数。CPU/GPU/内存预算必须由真实 Codex 30–60 分钟对照测量后确认。
