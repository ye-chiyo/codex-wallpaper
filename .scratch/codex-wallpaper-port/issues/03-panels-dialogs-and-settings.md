# 03: 侧栏、面板、弹窗与设置适配

**阶段：** P2 · 界面

**What to build:** 让壁纸在左右侧栏和 Codex 界面组件开合时保持自然，面板、弹窗和设置继续可读可操作。

**Blocked by:** 01

**Status:** ready-for-human

**复用边界：** 参考上游表面遮罩设计；为 Codex 重做面板容器、主题、焦点和 DPI 适配。DSH 的 slots 与侧栏注册不搬入。

## 验收标准

- [ ] 左右侧栏、文件/浏览器/终端面板、弹窗与设置正确分层；复杂内容保留实底，不为透明效果改写内嵌网页或编辑器。
- [ ] 明暗主题、窗口与应用缩放、面板开合时无错位或遮挡；弹窗焦点与键盘操作正常。

## 人工验收

- [ ] 在真实 Codex 依次操作面板、弹窗和设置，测试开合、缩放和明暗切换；有不同 DPI 显示器则跨屏移动，否则记录未覆盖。
