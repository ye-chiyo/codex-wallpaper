# 09: 播放代表性 Web 壁纸并隔离权限

**阶段：** P4 · 素材

**What to build:** 在 Codex 主界面播放受限的 Web 壁纸，联网只能由用户主动允许。

**Blocked by:** 07

**Status:** ready-for-agent

**复用边界：** 评估复用上游 Web 媒体准备与消息协议；为 Codex 验证或重做独立容器、素材供料、网络权限和输入边界。

## 验收标准

- [ ] 离线样本可播放；需联网素材清楚标识且默认拒绝，主动允许后才可访问网络。
- [ ] 验证 Web 壁纸不能读取 Codex 内容或任意本机路径；壁纸互动不抢点击、滚动、输入和焦点。隔离不能成立则该类不启用。
- [ ] 逐个记录实际样本的原生播放、降级或不支持结果；失败时宿主可继续使用。

## 人工验收

- [ ] 用实际离线样本和受控联网样本，分别验证未允许、允许及故障场景；在壁纸互动时操作聊天、输入框和卡片。
