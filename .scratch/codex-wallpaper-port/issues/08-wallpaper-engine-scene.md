# 08: 播放代表性 Scene 壁纸

**阶段：** P4 · 素材

**What to build:** 在 Codex 主界面运行代表性 Wallpaper Engine 场景，不能原生播放时给出明确结果和可用降级。

**Blocked by:** 07

**Status:** ready-for-human

**复用边界：** 验证上游 WebWallGL、Scene 媒体准备及播放桥能否脱离 DSH；为 Codex 新做容器、生命周期与资源限制接线。

## 验收标准

- [ ] 用真实场景样本核对渲染、暂停、恢复和失败处理；坏场景不能影响 Codex 日常操作。
- [ ] 按样本记录原生播放、静态/视频降级或不支持；降级不计原生兼容，不宣称全创意工坊兼容。

## 人工验收

- [ ] 用本机代表性 Scene 逐个选择、暂停恢复和切换，核对渲染表现以及降级/不支持提示。

## Comments

- 2026-11-13：离线候选接入固定版本 `webwallgl@3.0.0`。选中且可装入预算的 Scene 会加载引擎并以原生 Scene 播放；引擎缺失、包过大或加载失败时使用作者预览图并明确标记“预览降级”。真实创意工坊样本的渲染与暂停恢复仍待统一验收。
- 2026-11-13：录屏复现快速切换后旧 Scene 与新 Scene 交替闪动。根因是旧 `load()` 的延迟失败回调会在新壁纸生效后继续回写旧预览。现以渲染代次隔离所有图片、视频和 Scene 的异步回调；回归覆盖“旧 Scene 被新图片替代后仍延迟失败”。当前实例连续切换 Scene 降级、Web、两个原生 Scene、视频并回到原生 Scene，最终稳定为 1 层、1 个 canvas、0 个 iframe，状态为 `scene-native`。
- 2026-11-14：进一步确认“旧素材迟到”会无条件重启当前壁纸。现仅当迟到素材仍匹配当前选择时才重绘；其他响应只缓存并刷新面板。受控桌面录屏中，从“星极”切到“长离”仅有约 1–2 帧首帧过渡后稳定；20 次混合切换的 50ms 采样最大值为 1 根、1 控制根、1 样式、1 壁纸层、1 Scene 容器和 1 canvas。用户原录屏的持续约 0.47 秒交替未在当前构建复现，保留真实设备继续观察。
