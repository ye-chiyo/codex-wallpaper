# 13: 核实原入口自动生效

**阶段：** 并行 · 启动

**What to build:** 核实能否从原 Codex 入口自动接入壁纸，并保持日常登录、已有聊天和撤销能力。

**Blocked by:** 无。专用入口 P0b 已通过；本单可并行研究，不阻塞 P1。

**Status:** ready-for-agent

**复用边界：** 复用本仓库的 P0 证据、只读核验和撤销对照；原项目 DSH 启动机制不适用于 Codex，宿主接入要单独验证。

## 验收标准

- [ ] 若找到可行路径，保留原入口、官方包和日常 profile；自动生效且无需开终端或发指令，并可撤销。不修改受保护安装文件，不新建空白 profile。
- [ ] 若仍找不到可行路径，记录尝试证据与阻塞；专用入口保留为候选，不能记作原入口通过，是否作为正式入口由用户另行决定。

## 人工验收

- [ ] 有可行候选才安排手动冷启动：用原入口确认自动生效、原账号和同一个已有聊天；然后核对撤销后的原入口仍正常。无候选则该人工项未通过。
