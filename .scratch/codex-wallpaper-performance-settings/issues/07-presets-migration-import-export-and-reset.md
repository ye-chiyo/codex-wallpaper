# 07: 预设、迁移、导入导出与分组恢复闭环

**What to build:** 支持保存、应用和重命名外观与播放参数组合；用户在选择预设后继续调整时进入自定义状态。导出仅携带约定的外观与播放参数，不包含素材文件、个人路径、聊天或凭据；导入前校验版本、结构和数值范围，失败时不改变现有设置。分组恢复默认、恢复全部设置和移除素材必须语义不同；缺失字段回落默认值，小范围迁移保留已有收藏、轮播和素材选择。

**Blocked by:** 03 · 按证据收敛设置交互与跨窗配置同步开销；05 · 播放、性能档位与后台策略闭环；06 · 全局与分区画面外观闭环。

**Status:** ready-for-human

**Reuse boundary:** 复用现有配置对象作为单一真源及现有导入素材/停用清理入口；不复制手写字段清单，不把预设导出接入素材数据库或宿主个人数据。

**Human action:** 无视觉评审要求；真实路径可沿用同候选设置面板完成完整导入导出闭环。

- [x] 预设可保存、应用、重开恢复；应用后手动调整参数会变为自定义，不会静默继续显示为原预设。
- [x] 导出内容仅含约定设置，不出现素材、个人路径、聊天或凭据；导入有效文件后实际生效，非法版本、结构或越界值不改变现有设置。
- [x] 分组恢复默认、恢复全部设置和移除素材的作用范围清楚且互不混淆；恢复外观不删除壁纸、导入文件或收藏。
- [x] 旧配置缺字段使用默认值，小范围迁移后当前素材、收藏和轮播保留；跨窗最终配置一致。
- [x] 保存、应用、重开、导出、导入、实际应用形成完整闭环，覆盖失败保留旧值；现有浏览器回归和同候选实机路径通过。
