# 05: 播放、性能档位与后台策略闭环

**What to build:** 在设置面板中提供静音与音量、性能优先/均衡/自定义档位、适用的帧率或质量控制、不可见暂停和轮播。档位必须展示实际修改的参数与取舍，默认仍保持现有 30 FPS 方向；图片等不适用类型不显示虚假 FPS，视频区分绘制上限与媒体解码，Scene 只使用已安装版本真实支持的能力，Web 无法控制 iframe 内部时明确说明限制。控件即时生效、可靠保存，并在重开和跨窗后恢复。

**Blocked by:** 03 · 按证据收敛设置交互与跨窗配置同步开销；04 · 带分组壳的壁纸库搜索、筛选、收藏与状态闭环。

**Status:** ready-for-human

**Reuse boundary:** 复用现有工具栏和快捷键启停、播放器音量/帧率/暂停入口、Scene 已安装接口、轮播计时器和现有配置链；不复制启停状态，不把无效质量项做成可拖动控件。

**Human action:** 无视觉评审要求；真实验收使用代表性视频和 Scene 验证实际效果。

- [x] 静音、音量、性能档位、适用帧率/质量、不可见暂停和轮播均能实际生效并可靠保存；启用/停用继续复用现有入口。
- [x] 性能档位显示参数组合和取舍，选择后能看到当前档位；再手动调整参数时状态变为自定义，不静默改变默认画质方向。
- [x] 图片不显示帧率效果；不支持的质量或播放器能力不产生假成功，视频、Scene 与 Web 的适用范围和限制文案准确。
- [x] 音量、帧率及支持的原位参数调整不重载素材；关闭重开和跨窗同步后值一致，窄窗口和键盘可操作。
- [ ] 现有浏览器回归覆盖各素材能力分支，同候选实机验证视频和 Scene；交付实际生效值、限制及性能相关证据。

## Comments

2026-11-17：新增性能优先、均衡和自定义状态，默认均衡保持 Scene 30 FPS 与不可见暂停；性能优先使用 Scene 15 FPS，手动改变 Scene 上限或不可见暂停策略会进入自定义。静音与音量分离，音量调到正值会解除静音。视频按源解码并直接合成，不显示伪造绘制帧率；图片不显示 FPS；Scene 只接入已安装的 `setFps`/暂停接口；Web 明确保留 iframe 内部不可控限制。浏览器夹具验证即时生效、关闭重开、跨窗原位同步和当前媒体节点不变。同候选真实视频与 Scene 验收仍需在实际加载集成候选后执行，因此末项保持未勾选。

2026-11-17：独立 Spec 审查后补全档位取舍文案，并让摘要按当前素材说明适用范围。图片和 Web 的不适用暂停控件明确禁用，Web 能力说明与实际限制一致。

2026-11-18：最终集成审查确认“自定义”档位不能回弹为旧命名档位。用户直接选择自定义时保留当前 FPS 与后台暂停参数并立即持久化；浏览器夹具增加直接选择自定义的覆盖。
