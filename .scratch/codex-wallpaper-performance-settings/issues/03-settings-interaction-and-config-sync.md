# 03: 按证据收敛设置交互与跨窗配置同步开销

**What to build:** 依据基线已确认的热点，优化设置面板打开、关闭、连续调节、保存、跨窗同步和预览刷新中的重复工作。外观、音量及可原位更新的播放参数不得无故重新加载素材；连续输入允许合并持久化，但最终值必须可靠落盘并在重开后恢复。跨窗更新只应用相关变化，不因无关设置字段触发素材重载或完整面板重建。

**Blocked by:** 01 · 冻结当前候选并建立性能基线、预算。

**Status:** ready-for-human

**Reuse boundary:** 复用现有本地配置、存储事件、跨窗广播、视觉应用和播放器热更新入口；不建立平行状态机、第二套存储或通用状态框架。

**Coordination:** 逻辑前置仅为 01；本单与 02 共用运行时和共享夹具，属于单写者串行修改，实际执行排在 02 之后。

**Human action:** 除同版候选加载外无额外人工步骤。

- [x] 仅修改 01 已确认的设置交互或同步热点；未命中路径不改，并记录证据。
- [x] 调整外观、音量及受支持的原位播放参数不重载当前素材；更新缩略图或无关预览不重建整个设置区域，不破坏滚动位置。
- [x] 连续输入期间允许合并保存，但停止输入后的最终值可靠落盘；关闭并重开面板、跨窗口同步后均恢复一致最终值。
- [ ] 设置交互时延达到 01 预算，无重复保存、过期同步覆盖新值或由无关字段触发的素材重载。
- [ ] 现有浏览器回归和同候选实机设置路径通过；交付前后交互数据、原始采样及限制。
