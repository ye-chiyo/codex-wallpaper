# 06: 全局与分区画面外观闭环

**What to build:** 提供壁纸暗化、模糊、不透明度、适用类型的保持比例填充或完整显示，以及全局界面读底和聊天、侧栏/顶部、右侧面板、设置面板的必要分区覆盖。分区默认继承全局，可单独覆盖并恢复继承；壁纸模糊与界面雾化分开，壁纸不透明度与面板读底分开，有限的边框和雾化只在实际生效时出现。所有调整即时预览、可靠保存，并在明暗主题与窄窗口中保持可操作。

**Blocked by:** 03 · 按证据收敛设置交互与跨窗配置同步开销；04 · 带分组壳的壁纸库搜索、筛选、收藏与状态闭环。

**Status:** ready-for-human

**Reuse boundary:** 复用现有主题色、半透明材质、布局定位、壁纸视觉应用和未提交的视觉候选；不新增实时模糊层、不重做 Codex 布局、不复制同一效果的多个独立控件。

**Coordination:** 与 05 共用设置模型、配置和运行时样式，实际执行排在 05 之后，不并行修改同一面板与样式。

**Human action:** 用户负责最终视觉与审美确认；agent 只检查控件可达、可点击、可输入、可滚动及参数真实作用。

- [x] 壁纸暗化、模糊、不透明度和适用素材的适配方式即时生效、可靠保存，且不重载当前素材。
- [x] 全局读底及聊天、侧栏/顶部、右侧面板和设置面板的覆盖/恢复继承行为正确；分区覆盖不会由无关滑块重复控制。
- [x] 壁纸模糊与界面雾化、壁纸不透明度与面板读底语义分离；不可靠的高级效果不呈现为可拖动但无效果的控件。
- [x] 明暗主题和宽窄窗口下控件可到达、可操作、可滚动；停用再启用后设置、主题和当前候选样式保持。
- [ ] 现有浏览器夹具验证继承、覆盖、恢复、主题和值保存，同候选实机完成功能检查；视觉审美项留待用户验收。
