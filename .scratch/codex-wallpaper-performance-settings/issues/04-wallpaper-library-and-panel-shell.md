# 04: 带分组壳的壁纸库搜索、筛选、收藏与状态闭环

**What to build:** 将壁纸设置组织为壁纸库、播放与性能、画面与界面、预设与恢复四个清晰区域，常用项优先、高级项按需展开，并先完成壁纸库行为：按标题搜索、按类型筛选、按收藏筛选，显示当前素材及明确的加载/兼容/降级状态。导入素材与 Wallpaper Engine 素材共用同一套查找、选择和收藏操作，面板在明暗主题、窄窗口、键盘操作和滚动下仍可完成完整流程。

**Blocked by:** 01 · 冻结当前候选并建立性能基线、预算。

**Status:** ready-for-human

**Reuse boundary:** 复用现有半透明面板、素材卡、收藏/轮播数据、预览懒加载和按需素材通道；不新增列表虚拟化、通用数据层或另一套素材扫描。

**Coordination:** 与 03 共用面板和配置更新路径，实际执行排在 03 之后，不并行写入同一运行时。

**Human action:** 用户暂不需要审美验收；真实 Codex 功能抽查需同版候选已加载。

- [x] 设置面板显示四个明确区域，常用操作优先；后续区域可先只呈现必要入口，不制作无效果控件。
- [x] 标题搜索、类型筛选和收藏筛选共同作用于导入与 Wallpaper Engine 素材；当前选择、加载中、原生、预览降级和失败状态清楚可见。
- [x] 键盘可到达搜索和筛选控件，窄窗口可滚动到全部库内容；收藏、轮播、当前选择和已加载预览在关闭重开后保留。
- [x] 搜索或筛选不触发不必要的素材重载；缩略图按需加载并保持滚动位置，不因预览返回重建无关卡片或设置。
- [ ] 现有浏览器夹具覆盖完整库操作，同候选实机完成搜索、筛选、收藏、选择和重开；交付功能证据，不代做视觉审美结论。
