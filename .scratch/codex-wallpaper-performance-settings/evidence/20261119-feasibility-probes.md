## T1：File-backed 视频

素材为 `1791074903/明日方舟最最最最终.mp4`，`115500404` 字节，H.264 1920 × 1080、30 FPS，`moov` 位于文件前部。

通过真实 CDP `DOM.setFileInputFiles` 把文件交给当前主页面中的临时隐藏输入。页面没有读取完整 `arrayBuffer`，没有接收 Base64 视频，也没有创建完整内存副本。播放器直接使用 File 的 `blob:` URL。

| 指标             |                                                                      结果 |
| ---------------- | ------------------------------------------------------------------------: |
| `loadstart`      |                                                                  105.8 ms |
| `loadedmetadata` |                                                                  122.6 ms |
| `loadeddata`     |                                                                  164.9 ms |
| `canplay`        |                                                                  164.9 ms |
| 第一到第二帧     |                                                     File 可实际解码和播放 |
| 最终状态         | `readyState=4`，`videoWidth=1920`，`videoHeight=1080`，`currentTime` 前进 |

结论为通过。File object 可由真实 Codex 主页面直接交给原生视频并快速起播。

## T2：尾部 `moov` 虚拟 Blob

素材为 `1986730797/明日方舟X轻音少女.mp4`，`75689196` 字节，`moov` 位于 `mdat` 之后。

## T3：单进程、单 CDP 会话

对当前路径和合并路径交替运行 10 组。当前路径启动两个独立 Node 进程并建立两次 CDP 连接，先核验目标，再执行页面表达式。合并路径在一个 Node 进程和一个 CDP 会话中完成同一组操作。

| 路径                          |   中位数 |      p95 |     最大 |
| ----------------------------- | -------: | -------: | -------: |
| 两个 Node 进程、两次 CDP 连接 | 224.1 ms | 243.6 ms | 243.6 ms |
| 一个 Node 进程、一次 CDP 连接 |   3.7 ms |  15.5 ms |  15.5 ms |

单会话合并将固定链路的中位数缩短约 `220.4 ms`，p95 缩短约 `228.2 ms`。目标核验和页面执行共用会话时均通过。

另用当前包内 EXE、独立临时 profile 和独立 `CODEX_HOME` 启动一次隔离冷实例。当前工作实例保持运行，隔离实例只用于页面发现和单会话请求，随后按本进程树清理。

| 冷启动阶段                                   |      时间 |
| -------------------------------------------- | --------: |
| 启动进程到精确 `app://-/index.html` 目标可用 | 2631.5 ms |
| 目标可用到 WebSocket 会话建立                |   22.1 ms |
| 会话建立到 `Page.getFrameTree` 核验完成      |   80.3 ms |
| 目标可用到页面 `readyState=complete`         |  165.3 ms |

隔离实例的主页面在约 `2.63 s` 可用，单 CDP 会话完成核验和页面读取后总观察时间约 `2.80 s`。这证明冷进程中使用单会话完成目标核验和页面执行可行，固定链路不需要旧实现那种重复 Node 进程与连接。直接 EXE 启动没有 MSIX 包标识，因此这组数据不能替代正式专用入口的最终启动对比。
