# 04: 输入区底衬与界面组件视觉收口

**What to build:** 消除输入框后方比输入框大得多的黑色矩形，同时保留输入框本体、长聊天、工具卡片、代码、差异、侧栏、面板和弹窗的可读实底与正常操作。

**Blocked by:** 01 · 适配当前 Codex 更新并恢复壁纸。

**Status:** ready-for-agent

- [ ] 输入框后方的大面积宿主底衬恢复透明，壁纸连续显示到输入区边缘；输入框本体、代码、差异和工具卡片仍有足够读底。
- [ ] 明暗主题下文字可读；壁纸层不拦截点击、滚动、文本选择、复制、焦点和键盘输入。
- [ ] 控制按钮、设置面板、侧栏和弹窗层级正确；不为视觉透明改写内嵌网页或编辑器内容。
- [ ] 保留并验证当前已经存在但尚未统一提交的底衬修复；真实问题由计算样式和用户可见截图共同证明。
- [ ] 回归覆盖“输入框本体有底衬、输入框后方宿主底衬透明、工具卡片可点击、输入框可获得焦点、文字可选择”。删除只重复上述行为或只断言脆弱 CSS 文本的测试。
- [ ] 新增选择器必须对应已复现的 Codex DOM 结构或稳定语义属性；优先复用现有主题变量和表面规则，不维护第二套固定主题色。
- [ ] 交付前在真实 Codex 检查输入、选区、复制、工具卡片展开、左右面板和明暗主题，并保存不含聊天正文的视觉证据。
