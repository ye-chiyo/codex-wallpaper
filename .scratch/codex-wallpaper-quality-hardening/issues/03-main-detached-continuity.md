# 03: 聊天与变更页保持同一壁纸

**What to build:** 用户在 Codex 聊天与“变更”页面之间切换时，相同壁纸保持可见。未加载的素材使用已有作者预览或上一帧过渡，不出现黑闪、默认渐变闪入、旧新画面交替或重复播放器。

**Blocked by:** 01 · 适配当前 Codex 更新并恢复壁纸。

**Status:** ready-for-agent

- [ ] 聊天主页面和变更 detached 页面都通过已核验的精确目标承载同一运行时契约和同一份全局配置；不把 Avatar 或任意 `app://` 页面纳入。
- [ ] 自动回归模拟“聊天 → 变更 → 聊天”，验证两个页面读取同一当前选择，当前可见页面有且只有一层壁纸，不可见页面暂停。
- [ ] 切换期间不回到内置渐变；未取得完整主素材时保留作者预览或已有画面，Scene 首帧成功后再替换预览。
- [ ] 快速多次往返和切换图片、视频、Scene、Web 预览后，只保留一个活动播放器；旧异步回调不能重启当前壁纸。
- [ ] 页面切换不破坏输入、点击、滚动、文本选择和快捷键；变更页只需增加真实 DOM 证明必要的样式适配，不复制聊天页表面规则。
- [ ] 素材宿主继续复用现有按需读取、分块传输、Scene 加载和 Web 沙箱逻辑。两个页面需要同时服务时复用同一请求处理，不复制素材库或配置状态。
- [ ] 自动测试先在现有页面运行时接缝稳定复现黑闪或页面缺失，再以最小改动通过；不得只用私有变量或 CSS 文本断言代替用户可见行为。
- [ ] 真实 Codex 连续至少 10 次切换聊天与变更页，交付前完成截图或录屏视觉检查，记录黑闪、默认渐变、重复播放器和控制按钮状态。
