# 方案 A：主界面壁纸点击切换

Status: ready-for-agent

## Problem Statement

已安装的专用入口使用本地 File 播放大视频。真实 Codex 的前置 moov 视频在 20 次悬停后切换中有 8 次停在首帧交接。候选视频已有 1920×1080 尺寸、充分数据，播放时钟也在推进，主界面壁纸仍停留在旧画面。前置和尾置素材的选中反馈都超过既定预算。预先解码候选还可能抢占聊天输入、滚动和当前壁纸使用的资源。

## Solution

先在真实 Codex 复现前置视频交接并定位根因。点击后立即反馈选择，再使用已有本地 File 通路按需读取。候选以原尺寸、用户已有的布局和播放设置准备首帧，成功后接替旧画面。悬停和只按下均保持现有卡片展示。用同机对照同时验证切换速度和日常交互开销。

## User Stories

1. 作为 Codex 用户，我希望点击就能看到卡片选中和加载状态，以便知道选择已收到。
2. 作为 Codex 用户，我希望悬停扫过视频卡片时保持聊天流畅，以便浏览素材无需付出视频准备的开销。
3. 作为 Codex 用户，我希望按下后取消点击时维持当前画面，以便误操作不触发解码。
4. 作为 Codex 用户，我希望本机大视频能在浏览器读到必要数据后开始，以便文件总大小少影响等待。
5. 作为 Codex 用户，我希望前置索引的视频可靠接替旧画面，以便避免长时间卡在加载状态。
6. 作为 Codex 用户，我希望兼容的尾置索引视频也快速出现正确画面，以便复用已有素材。
7. 作为 Codex 用户，我希望首帧遵循原始素材尺寸和已有适应方式，以便画质和构图由我的设置决定。
8. 作为 Codex 用户，我希望候选准备期间继续看到旧画面，以便避免空白和错误预览。
9. 作为 Codex 用户，我希望快速选择始终以最后一次有效点击为准，以便避免过期画面回跳。
10. 作为 Codex 用户，我希望停用可取消仍在进行的读取和交接，以便及时回收资源。
11. 作为 Codex 用户，我希望素材丢失或播放失败时保留旧画面并有明确状态，以便决定是否重试。
12. 作为 Codex 用户，我希望聊天输入和滚动的延迟保持稳定，以便持续使用主界面壁纸。
13. 作为 Codex 用户，我希望悬停和重复切换不会持续提高 CPU 或内存占用，以便长时间使用。
14. 作为 Codex 用户，我希望看到同机前后数据和失败样本，以便判断方案 A 是否足够。
15. 作为 Codex 用户，我希望在有实测后决定是否采用方案 B，以便由收益和资源成本决定范围。

## Implementation Decisions

- 沿用主规格的原始预算、路径保护和取消语义。本轮更新该规格中的预热交互，悬停和仅按下均不触发 File 交付、候选播放器或视频解码。
- 先比较播放事件、呈现回调注册和交付、素材身份与 generation、提交前后节点。对照实验每次改变一个条件。
- 复用运行时的首帧交接、播放释放和选中状态。先更新点击涉及的状态和控件，避免在交接的关键路径重复处理无关卡片或面板。
- 复用扫描素材身份、允许的路径、CDP File 通路、现有尾置索引处理和有原因的兼容回退。原始素材和画质设置由现有播放链处理。
- 视频经本地 File 通路播放到 1 GiB；512 MiB 仅作为 Base64 兼容回退上限。超过上限或 File 通路不可用时提交作者预览，并优先保留旧画面。
- 保留目前画面直至同一代次候选达到首帧条件。失败或取消使用既有状态与清理路径。

## Testing Decisions

- 最终验证沿用真实 Codex 专用入口；确定性回归沿用现有浏览器夹具和宿主协议测试。测试用户操作、可见画面、可观察协议与资源释放。
- 使用同一台机器、素材、窗口、可见性和设置做对照。分别记录点击至选中反馈、正确画面、连续推进帧。记录全部超时、失败、取消与文件交付。
- 复用约 110 MiB 前置和约 75 MiB 尾置素材，覆盖无预热点击、重复切换、A→B→C、A→B→A、停用、素材失败和录屏动态帧。重复切换与首次使用分别报告，已有系统缓存状态单独说明。
- 对照普通聊天输入和滚动、悬停扫卡、切换中与稳定播放时的交互延迟及 CPU、内存。保持相同活动壁纸，报告进程范围、采样区间、波动和回收。若出现可重复的日常交互退化，方案 A 不通过。
- 在既有夹具捕捉实际交接回归、未确认点击不产生视频请求、取消清理。用户负责视觉验收。

## Out of Scope

缓存正确首帧的方案 B、保留多个播放器、修改素材编码和画质、启动链的其他未验收工作。

## Further Notes

已有实机基线为 8cc9fb36。更早的悬停热切仅对照原行为，不作为方案 A 的重复点击样本。当前 Codex 窗口由用户控制退出和重启。
