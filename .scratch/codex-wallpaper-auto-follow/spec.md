# Codex 壁纸自动跟进（第一阶段）

Status: ready-for-human

## 目标

让专用入口在 Codex 正常升级后，不再要求每次手工增加精确版本和 EXE 哈希，同时保留失败关闭和原界面保护。

## 第一阶段范围

- 已登记版本继续使用“包全名 + EXE SHA-256”快速路径。
- 未登记版本只有在以下条件全部满足时进入兼容探测：
  - 包名、包族、Publisher ID、x64 架构和 Store 签名正确；
  - `OpenAI.Codex_2p2nqsd0c76g0!App` 登记仍可用；
  - 主程序位于安装目录，且 Authenticode 签名有效、签发者为 OpenAI；
  - 日常 profile、主进程和环回监听归属保持原有校验。
- 兼容探测必须确认当前主界面已经出现，才允许把壁纸会话标记为成功。
- 探测失败时停止注入、清理临时运行层并保持 Codex 原界面。
- 桌面入口遇到非零退出时显示包含具体原因的 Windows 弹窗。

## 非目标

- 不根据版本号直接放行任意安装包。
- 不附加到已经运行的普通 Codex 实例。
- 不强制关闭或重启 Codex。
- 不在第一阶段实现完整的多套 UI 适配器注册表。

## 验收

- 当前已登记版本仍走快速路径。
- 可信但未登记的新版本可在离线测试中到达 activation 边界。
- 签名错误、包身份异常和摘要漂移且签名不可信的版本仍失败关闭。
- 主界面未出现时，兼容探测在限定时间内失败并保留原界面。
- 启动失败时桌面入口显示中文原因弹窗，不静默退出。
- 原有 Node、PowerShell、登录入口和桌面包装器测试全部通过。
