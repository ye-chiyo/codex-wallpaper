# 01: 可信版本自动探测与失败弹窗

Status: ready-for-human

**What to build:** 第一阶段保留精确版本快速路径；可信但未登记的 Codex 版本进入运行时兼容探测。只有主界面实际出现、壁纸运行层可挂载并可清理时才算成功。桌面入口在失败时显示具体原因，不能静默退出。

**Blocked by:** None。

## Acceptance

- [x] 包名、包族、Publisher ID、Store 签名、架构、应用登记和 OpenAI Authenticode 签发者全部校验。
- [x] 未登记但可信的版本不再因缺少精确哈希而在 activation 前停止。
- [x] 未知、签名异常或身份不匹配的包仍失败关闭。
- [x] 兼容探测等待主界面出现；超时返回 `compatibility-probe-failed`。
- [x] 探测失败时不提交专用会话，原界面保留。
- [x] 桌面包装器把错误消息显示为 Windows 弹窗。
- [x] Node 73/73、启动器预检、启动入口、root 状态和桌面包装器测试通过。
- [ ] 等待一次真实未登记 Codex 版本的冷启动验收。

## Evidence

- 当前安装：`OpenAI.Codex_26.1117.4957.0_x64__2p2nqsd0c76g0`，快速路径状态输出 `CompatibilityMode: known`。
- 离线预检覆盖可信未登记版本、不可信签名、包身份异常、已知版本哈希漂移、应用登记缺失和日常目录缺失。
- 兼容探测测试覆盖主界面未出现时失败，以及主界面稍后出现时必须等待后再成功。
- 桌面入口测试确认真实错误弹窗标题、正文原因和退出码回传。
- 实际桌面快捷方式在已有专用实例时复用成功，没有新增 Codex 主进程。
- 部署后的桌面包装器已重新编译为 `CodexWallpaper-F2C052C613E9.exe`，桌面快捷方式已指向该文件；用真实二进制触发的错误弹窗只显示一次原因，并正确回传退出码。
