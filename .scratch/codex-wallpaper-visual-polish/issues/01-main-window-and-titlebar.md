# 01: 主窗口壁纸与顶部交互

**What to build:** 让主界面壁纸贯穿原有主窗口；顶部菜单、标题栏、左侧图标栏与项目栏共享随 Codex 主题变化的半透明材质与细边界，保留原生窗口操作。

**Blocked by:** 无，可直接开始。

**Status:** ready-for-agent

- [ ] 明暗主题下，顶部和左侧连贯，无露底亮条、突兀接缝或非预期模糊；复用现有主题并集中管理后续界面组件共用的材质与边界。
- [ ] 装饰层不拦截输入；复用现有夹具验证代表性顶部控件能响应点击。在获准后的真实界面用鼠标验证目录下拉、聊天标题和安全可测的顶部按钮。
- [ ] 保持标题栏原生定位，空白区可实际拖动窗口，原生窗口控制可用；不通过全局抬高层级、禁用拖拽或转发点击绕过问题。
