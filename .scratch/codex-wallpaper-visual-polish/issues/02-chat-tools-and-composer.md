# 02: 聊天读底、工具与输入

**What to build:** 在原有聊天中从阅读正文、展开工具和查看代码到输入都保持清晰可用，沿用统一材质。

**Blocked by:** 01 · 主窗口壁纸与顶部交互。

**Status:** ready-for-agent

- [ ] 较深的半透明读底铺满原有对话区；正文、普通状态和辅助信息共用底色，可展开工具行和代码保留必要的局部读底，无窄面板、重复读底或输入框外侧黑块。
- [ ] 输入框的细边框、圆角、悬停及焦点与共享材质协调。输入框可聚焦并接收键盘输入，文本可选择、聊天可滚动、工具行可展开。
- [ ] 复用现有夹具验证输入、焦点和外侧底衬等可稳定复现的行为；在获准后的真实界面复查操作和画面，不发送聊天。
