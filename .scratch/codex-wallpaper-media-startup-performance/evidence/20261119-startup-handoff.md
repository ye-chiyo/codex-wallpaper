## 修复后的协议

1. PowerShell 完成官方激活和现有进程、日常 profile、监听归属核验，启动一个隐藏的 Node 监督进程。
2. Node 在同一 CDP 会话核验唯一主目标的准确 URL 和 frame 来源，共用一次扫描结果与运行时载荷。PowerShell 收到核验信息后复核本机保护，允许该会话继续安装。
3. 绑定宿主后挂载运行时。首次恢复直接使用已绑定宿主，保留已存配置。Node 回报页面实际返回的运行时、样式哈希与宿主状态。PowerShell 写入专用标记并退出，监督进程继续服务素材。
4. 缺失目标时，唯一的监督进程在启动时限内继续等目标。核验拒绝或初始化失败时回收连接和宿主锁。已经开始挂载时，通过同一会话清除本次注入的界面与监听，且保留存储的配置。

回执包含 `TargetAcknowledgedMs` 和 `HostReadyMs`，以官方激活后同一个 PowerShell 单调计时器为基准。前者包括素材扫描以及接收目标信息，后者证明宿主已就绪。壁纸首帧及真实动态帧须在实际 Codex 另行测量。

## 复用和剩余验收

复用包和进程核验、CDP 发现及 frame 检查、已有素材扫描、`attachWallpaperHost`、首帧交接与 `disable` 清理。专用路径移除了第二次目标发现和旧入口的二次注入。新增的是父子进程间有限时的确认协议及启动失败回滚。独立的旧 CLI 仍供现有调用方与测试使用。

独立审查识别的两个生命周期问题已修复。File 回退原因随既有传输协议传给页面，由页面记录，宿主因此无需写入已关闭的 PowerShell 管道。通用停用清理被启动回滚复用，包括取消已开始但尚未交付的 File。替换回归合并进交接成功用例，取消断言使用真实浏览器行为，避免另测内部表达式。未引入新私有算法或并行配置。
