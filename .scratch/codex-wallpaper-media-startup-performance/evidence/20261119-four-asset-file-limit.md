## 原因

- `deepseek创越次元` 和 `DeepSeek娘4k超分60帧壁纸` 实际已播放，旧运行时仍把扫描条目当作完整内存素材，卡片因此错误显示“不可播放”。
- `《鸣潮》今昔` 是前置 `moov` 的 4680×2160 H.264。旧运行时收到过早的呈现回调后退出，候选视频在透明暂存层继续解码，却未接替旧画面。
- `吊桥-义妹生活/绫濑沙季` 为 564,467,901 字节，旧逻辑在 512 MiB 处直接拒绝。宿主随后发送了作者预览，但页面错误路径只更新状态，没有提交预览。

## 实现

- 视频通过本地 File 通路支持到 1 GiB。512 MiB 仅保留为 Base64 兼容回退上限。
- 文件超过 1 GiB，或大文件 File 通路不可用时，宿主发送作者预览。页面在无旧画面时提交预览，有旧画面时继续保留。
- 成功 File 播放和运行时素材状态共用现有 `playable`、`runtimeAssets` 和卡片状态，没有增加第二套播放状态。
- 未修改媒体文件、解码器、画质设置或悬停行为。
